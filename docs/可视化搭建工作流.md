# 可视化搭建工作流（说需求 → AI 逐个节点搭出来 → 你全程看着）

> 目标：**不再丢给你一个 `.json` 让你自己 import**。你说需求，AI 在 n8n 里
> **一步一步把节点搭出来**，同时 **DSH 玻璃浮窗自动打开内嵌 n8n 编辑器**，
> 每保存一次就自动刷新，你能看着工作流"长"出来。

---

## 用户怎么用（一句话）

在 DSH 里直接说需求，例如：

> 「帮我做一个工作流：收到 POST 请求后，把 body 里的 name 拼成问候语返回。」

AI 就会：创建工作流 → 打开内嵌编辑器 → 逐个加节点 → 连线 → 激活 → 让你点「触发」试。

**不想让它自己搭？** 浮窗里每个工作流都有「编辑」按钮，可以随时自己上手改。

---

## AI 的操作顺序（工具调用契约）

| 步骤 | 工具 | 说明 |
|---|---|---|
| 1 | `n8n_create_workflow` | 先建一个**空**工作流（`nodes: []`）。`settings` 缺省会自动补 `{}`。 |
| 2 | `n8n_open_editor` | **立刻**把 `workflowId` 交给浮窗 → 编辑器自动弹出。带 `note` 说明当前在做什么。 |
| 3 | `n8n_add_nodes` | **一次加一步**（例如先加触发器，再加处理节点），每次都传 `connections` 把线连上。 |
| 4 | （重复 3） | 每加一步都可以再调 `n8n_open_editor` 更新 `note`；浮窗检测到 `updatedAt`/节点数变化会**自动刷新** iframe。 |
| 5 | `n8n_activate_workflow` | 需要外部触发时才激活（工作流必须有真正的触发器节点：Webhook / Schedule 等）。 |
| 6 | `n8n_trigger_workflow` | 用 Webhook 路径试跑。⚠️ **激活后 webhook 注册是异步的，等 3–5 秒再触发**。 |
| 7 | `n8n_get_execution_status` / `n8n_list_executions` | 看结果。 |

### 关键约束（踩过的坑）

- **`n8n_create_workflow` 的 body 必须有 `settings`**（工具已自动补 `{}`）。
- **`n8n_update_workflow` / `n8n_add_nodes` 的 PUT body 必须有 `name`**（工具已自动沿用原名）。
- **`manualTrigger` 不算"可激活触发器"**：只有它的话 `publish` 会报
  `Workflow cannot be activated because it has no trigger node`。要么加 Webhook/Schedule，要么别激活。
- **Webhook 路径不能重复**：同一工作流里两个 Webhook 节点用同一 `path` → `publish` 报 **409 webhook path conflict**。
- **`publish` 会校验节点配置与凭据**：缺参数（如 `fileSelector`）或缺凭据（如 `googleSheetsOAuth2Api`）
  都会 **400**。缺凭据的节点可先 `"disabled": true` 绕过（可逆）。
- **节点类型必须是 n8n 真实支持的**：先用 `npm run scan:workflows` 体检（见 `docs/收尾审计报告.md`）。
- 每个节点需要 `id`、`name`、`type`、`typeVersion`、`position`；Webhook 节点还需要 `webhookId`。

### 提示词模板（给用户）

> 我要一个工作流：<用大白话说清输入、处理、输出>。
> 请用 n8n 工具一步步搭，每加一个节点就在浮窗编辑器里让我看到，搭完告诉我怎么触发。

## 浮窗（玻璃 HUD）里能看到什么

- **内嵌 n8n 编辑器**：直接嵌 n8n 页面（n8n 未设 `X-Frame-Options`）。顶部有
  **自动刷新** 开关（AI 每保存一次自动重载，让你看到最新画布）、
  **在系统浏览器打开**（桌面端会把 http 链接转交系统浏览器）、**关闭**。
- **工作流列表**：启用状态 + 「编辑」「启用/停用」「触发」按钮。
- **最近执行**：状态徽章 + 时间。
- **连接配置**：n8n 地址（默认 `http://127.0.0.1:5678`）+ API Key。

> 技术细节：桌面端主窗口 `webviewTag=false`，但配置了
> `setWindowOpenHandler → shell.openExternal`，所以「在系统浏览器打开」可用；
> 而 `iframe` 因为 n8n 没有 `X-Frame-Options` 可以直接内嵌。
